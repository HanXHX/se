=encoding utf8

=head1 NAME

se - Fast connection to SSH

=head1 SYNOPSIS

B<se> [I<OPTION>]... [I<PATTERN>]

=head1 DESCRIPTION

B<se> is a front end for SSH. It parses your SSH config file to pick your servers. You can add servers with comments in the config file.

Without I<PATTERN>, B<se> displays the host list and reads the selection on standard input. I<PATTERN> can be a host number, a favorite letter, or a fuzzy pattern (see se(5)).

=head1 OPTIONS

=over 4

=item B<-b>, B<--binary> I<BINARY>

Full path to SSH binary (default: /usr/bin/ssh)

=item B<-c>, B<--config> I<config-file>

Use an alternate SSH config file (default: ~/.ssh/config)

=item B<-h>, B<--help>

Display help and exit

=item B<-l>, B<--hostname-length> I<NUMBER>

Displayed hostname length (default: 24)

=item B<-o>, B<--out-columns> I<NUMBER>

Number of columns to display (default: 5)

=item B<-s>, B<--split-name>

Only display the first label of the hostname (myhost.domain.tld -> myhost)

=item B<-v>, B<--version>

Output version information and exit

=back

=head1 FILES

=over 4

=item I<~/.ssh/config>

Per user configuration file. See se(5) for further details.

=back
